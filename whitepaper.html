ABCR Whitepaper

A plain-language overview of AntiBank Crypto's experimental burn participation and epoch-based token reward model on BNB Smart Chain.

This document is informational, not financial advice. It is a project overview based on the stated contract parameters; it is not an independent smart-contract audit. Where implementation details are not verified, they are not presented as guarantees.

01 / Executive summary

AntiBank Crypto (ABCR) is an experimental BEP-20 token ecosystem on BNB Smart Chain. Participants can connect a wallet, burn ABCR tokens through the deployed smart contract, and request any eligible epoch-based token rewards according to the contract's rules. All transactions are recorded on-chain.

Burning tokens is irreversible. Claiming rewards is conditional on eligibility and contract logic; neither participation nor a burn guarantees a positive financial return.

03 / Burn participation

Burning ABCR removes the selected tokens from the holder's balance. The website invokes the contract function burnForShares(uint256). Burn participation may create accounting shares used by the reward system, but the precise allocation formula and timing must be confirmed in the deployed contract source.

Users should not assume that burning more tokens always results in a proportional or guaranteed reward.

04 / Epoch-based rewards

The project uses 30-minute epochs. The stated reward pool is 100 ABCR per epoch, subject to the overall reward minting limit and contract conditions. This is a pool for an epoch, not a promise of 100 ABCR to every participating wallet.

The website's claim(maxEpochs) function accepts a maximum number of epochs to process (1–24). Entering “1” requests up to one eligible epoch; it does not request exactly one token. Eligibility, payout and rounding are determined by on-chain logic.

05 / Supply and transparency

ABCR's maximum lifetime token creation is stated as 100 million, comprising 10 million initial tokens and up to 90 million reward tokens. Burning can reduce the outstanding supply; rewards may mint new tokens within the contract's lifetime limit. The current circulating supply is not a fixed number and should be read from live on-chain data.

06 / User experience

  1. Connect a compatible wallet to BNB Smart Chain.
  2. Read the token balance and current epoch data.
  3. Optionally submit an irreversible burn transaction.
  4. Check reward eligibility and submit a claim transaction when available.
  5. Verify transaction receipts and token transfers on BscScan.

For the current website release, wallet connection has been confirmed in browser Desktop Site mode. Mobile wallet handoff may not work reliably.

07 / Risks and limitations

  • Loss of tokens: Burned tokens cannot be recovered.
  • No guaranteed returns: Rewards and token market value are not guaranteed.
  • Smart-contract risk: Software bugs, unexpected behavior and economic design flaws may exist.
  • Wallet and network risk: Wrong networks, phishing, malicious extensions and lost keys can cause losses.
  • Transaction fees: BNB gas is required for on-chain actions, including failed transactions.
  • Liquidity risk: A token's ability to be traded or sold is not guaranteed.

08 / Development priorities

Potential development priorities include clearer wallet compatibility, improved transaction status, contract-level reward explanations, accessibility and public documentation. These are goals, not commitments or dated delivery promises.
